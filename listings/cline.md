# Cline MCP Marketplace issues

One issue per server at https://github.com/cline/mcp-marketplace/issues/new?template=mcp-server-submission.yml. Attach the folder's `icon.png` (400 x 400). Before sending, test that Cline can set the server up from `README.md` and `llms-install.md` alone.

## HyperLake

- **GitHub Repo URL:** https://github.com/cerebrixos-org/brand-mcp-servers/tree/HEAD/hyperlake
- **Logo Image:** `hyperlake/icon.png`
- **Reason for Addition:** HyperLake is a managed data lake. The hosted connector lets an assistant list clusters, manage catalogs and access grants, and inspect apps and agents with the signed-in user's permissions. Write tools carry destructive hints and need confirmation. Hosted over Streamable HTTP with OAuth, so there is nothing to install and no key to paste.

- **Logo Image:** `pulselake/icon.png`
- **Reason for Addition:** PulseLake Experience Ops lets an assistant create AI surveys, read submissions and respondents, and chat with Agent Copilots, inside the user's own tenant and permissions. Hosted over Streamable HTTP with OAuth, so there is nothing to install and no key to paste.
